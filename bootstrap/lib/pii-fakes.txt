# pii-fakes.txt — the declared fakes: documented examples, not people. The outbound flag pass's brief is
# generated from this file at every run (push step 5a): a string is fake ONLY if its WHOLE text equals an
# exact: entry or fully matches a re: entry; anything else, or anything uncertain, is flagged. Nothing else is.
#
# Changes only by PR, never by a skill or a run: an entry here is waved through every outbound flag pass on
# every machine, so a real string added once is a leak made permanent. Why nothing else is remembered:
# bootstrap/PII-SCAN-CONTRACT.md, "Why nothing is remembered".
#
# Format: one entry per line; `#` comments and blank lines ignored.
#   exact:<text>   the whole string equals <text> exactly ("Jane" alone is NOT Jane Q. Doe)
#   re:<regex>     Python re.fullmatch on the whole string — for the reserved ranges only
#   # means: <plain meaning>   REQUIRED on the line directly above every re: entry — the brief shows each
#                  pattern with it (a re: without one stops the run: CANNOT-CHECK)

# fictional phone range 555-0100..555-0199, any area-code form
# means: a phone number in the fictional 555-0100 to 555-0199 range, with or without an area code or +1
re:(\+?1[ .-]?)?(\(?[0-9]{3}\)?[ .-]?)?555[ .-]?01[0-9]{2}
# RFC 2606 / 6761 documentation domains, their URLs and addresses. Fixed vocabulary only — no free subdomain, path
# segment or address local part, so nothing in these can carry a real name, an employer or a client:
#   hosts: example.com / .org / .net / example.test, optionally behind www., docs. or api.;
#   paths: only the words docs, setup, guide, api, v1, path, page, index.html; local parts: a fixed list of example words.
# means: example.com, example.org or example.net (optionally https://, www./docs./api.), with only the path words docs, setup, guide, api, v1, path, page, index.html
re:(https?://)?(www\.|docs\.|api\.)?example\.(com|org|net)(/(docs|setup|guide|api|v1|path|page|index\.html))*/?
# means: an address at exactly example.com, example.org or example.net whose local part is you, user, me, someone, name, test, admin, jane, john, alice, bob, jane.doe or john.roe
re:(you|user|me|someone|name|test|admin|jane|john|alice|bob|jane\.doe|john\.roe)@example\.(com|org|net)
# means: the host example.test (optionally https://, www./docs./api.), with only the same fixed path words
re:(https?://)?(www\.|docs\.|api\.)?example\.test(/(docs|setup|guide|api|v1|path|page|index\.html))*/?
# means: an address at exactly example.test whose local part is one of the same fixed words
re:(you|user|me|someone|name|test|admin|jane|john|alice|bob|jane\.doe|john\.roe)@example\.test
# RFC 5737 documentation IPs
# means: an IPv4 address in a documentation range: 192.0.2.x, 198.51.100.x or 203.0.113.x
re:(192\.0\.2|198\.51\.100|203\.0\.113)\.[0-9]{1,3}
# SSNs the SSA never issues in the 000- and 666- areas. Not 9xx-: that is the IRS ITIN range, a real
# taxpayer number, so it is never a fake. Presidio rejects both areas, so neither ever fires as an SSN.
# Doc examples use 000-. A fixture that must FIRE uses a harness-only value: it lives in the test
# harness, never in a shipped file. Never write a 666- number anywhere.
# means: a US social security number in the never-issued 000- or 666- area, written NNN-NN-NNNN
re:(000|666)-[0-9]{2}-[0-9]{4}
